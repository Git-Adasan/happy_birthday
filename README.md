# Birthday Manager v2

Telegram-бот для управления днями рождения. Основа объединяет `happy` и `birhday`:

- асинхронный PostgreSQL через asyncpg;
- категории, карточки, поиск, редактирование и удаление;
- ввод даты `ДД.ММ.ГГГГ` или `ДД.ММ`;
- массовое добавление;
- календарь и статистика;
- напоминания за 30/14/7/3/1 день и в день рождения;
- несколько стилей готовых поздравлений;
- кнопка копирования текста на новых версиях Telegram Bot API;
- проверка дубликатов;
- экспорт списка в CSV;
- отдельный раздел «Сегодня»;
- заметки и безопасная миграция существующей PostgreSQL-схемы.

## Render

Создай PostgreSQL database и добавь переменные:

`BOT_TOKEN`, `DATABASE_URL`, `TZ_NAME=Asia/Almaty`

Build/Start:

```bash
pip install -r requirements.txt
python bot.py
```

Если у тебя уже есть старая БД от `happy`, новая версия сама добавит недостающие поля `has_year` и `note`.

## Локальный запуск

Скопируй `.env.example` в `.env`, впиши свой токен и `DATABASE_URL` (файл `.env` в git не попадает), затем `python bot.py`.
Папку `venv/` в архив и в репозиторий не кладём — на Render зависимости ставятся из `requirements.txt`.
